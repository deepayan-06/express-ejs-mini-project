# express-ejs-mini-project
A mini Instagram-style web app built with Node.js, Express.js, and EJS featuring dynamic pages, reusable templates, and custom styling.


express-ejs-mini-project is a server-rendered web application that displays Instagram-style user
profiles and posts. User data is stored in a `data.json` file and rendered dynamically
through EJS templates, with shared layout partials (like the page `<head>`) kept reusable
and DRY. I built this project to practise routing, templating, and serving static assets
in Express.
